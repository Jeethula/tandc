# Security Policy

## 🔒 Commitment to Privacy & Security

**T&C Clarity** is architected on a strict zero-telemetry, client-side first foundation:
- **Local Key Storage**: API keys are stored exclusively in `chrome.storage.local`.
- **Direct API Routing**: API calls are routed directly from your browser to Google's official Gemini endpoint or your localhost (Ollama).
- **No Third-Party Analytics**: Zero logging, tracking scripts, telemetry, or remote proxy servers.

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability or privacy flaw in T&C Clarity:

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories on [https://github.com/Jeethula/tandc/security/advisories](https://github.com/Jeethula/tandc/security/advisories) or directly via email to **[jeeththenthar@gmail.com](mailto:jeeththenthar@gmail.com)**.
3. Provide a detailed summary, proof of concept, and steps to reproduce.
4. We will acknowledge your report within 48 hours and work with you on a resolution before making any public disclosure.
